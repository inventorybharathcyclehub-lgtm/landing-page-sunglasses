## PROMPT ENHANCEMENT TIPS

Add these modifiers to any prompt to improve quality:

**For Midjourney:**
- `--v 6 --style raw` — most realistic
- `--ar 4:5` — Instagram portrait
- `--q 2` — highest quality

**For DALL-E 3:**
- Add "photorealistic" and "shot on Canon R5" for realistic images
- Add "product photography" for clean product shots

**For Adobe Firefly:**
- Use "Generative Fill" for product placement on custom backgrounds
- Use "Text to Image" with style: "Photo" for lifestyle shots

**For Ideogram:**
- Best for text-on-image or graphic design elements
- Great for creating infographic backgrounds and brand pattern tiles

## HOW TO USE THESE IMAGES

1. Generate 3–5 variations of each prompt
2. Select the best 1–2 from each category
3. Edit in **Canva** (add brand text overlays, price callouts, CTA buttons)
4. Resize for each platform:
   - Instagram Feed: 1080 × 1350px (4:5)
   - Instagram Reel cover: 1080 × 1920px (9:16)
   - Website hero banner: 1920 × 900px (16:9)
   - Product card: 800 × 800px (1:1)
